# DealKern: offene Ankaufsprofil-Daten

85 Aggregatzeilen zu einem Bestand von 2.693 öffentlich kommunizierten Ankaufsprofilen in DACH, Erhebungsstand Oktober 2026. Dazu ein deskriptiver Datenbericht und ein lokaler Anschreiben-Helfer für Makler.

## Grenzen

Keine Vollerhebung, keine Zufallsstichprobe und keine Transaktionsstatistik. Die Einheit ist ein erfasstes Profil, nicht zwingend ein wirtschaftlich unabhängiger Käufer. Nutzungsarten und regionale Gebiete überschneiden sich. Details stehen im Datenbericht und in data/README.md.

## Nutzen

- data/investorenmarkt-dach-2026.csv: vollständiger Aggregat-Snapshot, ohne Investorennamen und Kontaktdaten.
- docs/data/ankaufsprofile-dach-2026-datenbericht.pdf: drei Seiten mit Ergebnissen, Methodik und Grenzen.
- docs/objektanfrage/: Anfrage aus Eckdaten vorbereiten; ohne Datenübertragung, Speicherung oder Zugriff auf Webseiten.

Die Erweiterung ist separat als Installationspaket vorbereitet. Diese Website ist bereits ohne Installation nutzbar.
